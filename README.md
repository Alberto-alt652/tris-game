# Gioco del Tris (Tic-Tac-Toe)

[![Demo Live](https://shields.io)](https://alberto-alt652.github.io/tris-game/)

Un'applicazione web leggera, moderna e minimale per giocare al classico **Tris** direttamente dal browser. Il progetto è realizzato esclusivamente con tecnologie front-end standard (HTML, CSS e JavaScript) senza l'ausilio di framework esterni.

## 🚀 Caratteristiche

* **Design Moderno:** Interfaccia scura (Dark Mode) con uno stile minimale, transizioni fluide ed elementi visivi curati.
* **Colori Differenziati:** Identificazione immediata delle mosse grazie al colore azzurro per il giocatore **X** e rosso per il giocatore **O**.
* **Logica di Gioco Integrata:** Controllo automatico in tempo reale delle combinazioni vincenti e degli scenari di pareggio.
* **Reset Rapido:** Pulsante dedicato per svuotare la griglia e avviare istantaneamente una nuova partita.

## 🛠️ Tecnologie Utilizzate

* **HTML5:** Struttura semantica della pagina e della griglia di gioco.
* **CSS3:** Layout responsive basato su *CSS Grid* e *Flexbox*, personalizzazione dei font e gestione degli stati di hover.
* **JavaScript (ES6):** Gestione dello stato dell'applicazione, manipolazione del DOM ed esecuzione degli algoritmi di verifica della vittoria.

## 📂 Struttura del Progetto

Il progetto si compone di tre file principali:
* `index.html` - La struttura della pagina, della griglia 3x3 e dei controlli.
* `style.css` - Foglio di stile per il design minimale e la palette di colori scura.
* `script.js` - La logica per i turni, le condizioni di vittoria e il riavvio della partita.

## 🎮 Come Avviare il Gioco

Non è richiesta alcuna installazione o configurazione di server locali. 

1. Scarica o clona i tre file all'interno della stessa cartella.
2. Assicurati che i file CSS e JavaScript siano correttamente collegati all'interno del file HTML.
3. Fai doppio clic sul file `index.html` per aprirlo in un qualsiasi browser web (Chrome, Firefox, Edge, Safari).
